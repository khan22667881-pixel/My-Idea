# My-Idea
# 🎓 Subject Explorer

Pick a field of study and get an AI-generated overview covering:

- **Scope**: how broad the subject is, its major areas and career paths
- **Key points**: the core concepts and skills
- **Importance**: why the subject matters
- **Inter-relationship**: how it connects with other subjects
- **Future**: emerging trends and open challenges

Built with [Streamlit](https://streamlit.io) and Google Gemini (Flash model) through the `google-genai` SDK.

## Features

- Choose from preset categories or type any custom subject
- Three explanation levels: Beginner, Intermediate, Advanced
- Results organised in tabs, downloadable as a Markdown report
- Results cached for one hour to save API quota
- Friendly error messages (bad API key, quota reached, wrong model name)

## Run locally

1. Install Python 3.9 or newer.
2. Get a free Gemini API key from <https://aistudio.google.com/apikey>.
3. Install and run:

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

4. Provide your API key in **one** of these ways:
   - Paste it into the sidebar when the app opens, or
   - Create `.streamlit/secrets.toml` containing:

     ```toml
     GEMINI_API_KEY = "your-key-here"
     # GEMINI_MODEL = "gemini-3.5-flash"   # optional
     ```

   - Or set an environment variable: `export GEMINI_API_KEY="your-key-here"`

> Never commit your API key or `secrets.toml` to GitHub.

## Changing the model

Google renames and retires models over time. The default is set at the top of `app.py` (`DEFAULT_MODEL`). You can override it without editing code by:

- typing a different name in the **Model** box in the sidebar, or
- setting `GEMINI_MODEL` in secrets or as an environment variable.

If the chosen model is not found, the app automatically tries the fallback listed in `FALLBACK_MODELS`.

## Deploy on Streamlit Community Cloud

1. Push this project to a GitHub repository.
2. Go to <https://share.streamlit.io> and sign in with GitHub.
3. Click **Create app**, choose your repository, branch `main`, and main file `app.py`.
4. Open **Advanced settings → Secrets** and paste:

   ```toml
   GEMINI_API_KEY = "your-key-here"
   ```

5. Click **Deploy**.
